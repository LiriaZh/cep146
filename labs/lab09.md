Exercise 1: Your First Prompts

Scenario 1: Declining a Party Invitation
Poor Prompt: Write an email to decline a party invitation.
Good Prompt: Write a polite email to my friend for declining their party invitation because of so reason I can't make it. Thank them for inviting me, apologize for not being able to attend, and wish them to have a good party moment.
Comparison: The poor prompt is too general because it does not specify the audience, reason and tone. The good prompt provides clear instructions and context, allowing AI to generate a more appropriate and personalized email.

Scenario 2: Need help with understanding photosynthesis for a presentation
Poor Prompt: Explain photosynthesis.
Good Prompt: Explain photosynthesis to elementary students who have no knowledge about biology. Use simple English and organize the explanation into note form (bullet points) for a classroom presentation. Provide real-life examples as well.
Comparison: The poor prompt does not specify the target audience or expected format. The good prompt identifies the audience, their knowledge level, the required information, and the presentation format. This helps AI provide an explanation that is easier for students to understand.

Scenario 3: Recipe Suggestions
Poor Prompt: Give me some recipes.
Good Prompt: Suggest three beginner-friendly step-by-step instruction recipes using chicken, eggplant, and potatoes. I prefer meals that can be made within an hour. I have basic cooking skills and access to a stove and microwave.
Comparison: The poor prompt may include the ingredients that users don't have, with dietary restrictions. The good prompt provides specific requirements and limitations, helping AI generate recipes that are practical and suitable for the user.

Pair Discussion
1. Which prompts are clearer?
The good prompts are clearer because they include specific instructions, background information, constraints, and expected output formats.

2. What information might be missing?
Important details such as the target audience, preferred tone, available resources, dietary restrictions. Without these details, AI may generate responses that do not fully meet the user’s expectations.

3. How could you improve them?
By adding relevant context, specifying requirements, defining limitations, and requesting a particular output format.

Exercise 2: Problem-Solving with AI

Selected Scenario B: Learning New Skills - C Language

Step 1: Identify Current Skill Level
Prompt: I am a beginner in C programming and have some basic knowledge of variables and functions. Identify my skill level by asking me some questions about C programming, and recommend which topics I have to improve in.
Purpose: To tell the AI user's current programming knowledge and provide personalized learning recommendations.

Step 2: Learn Programming Concepts
Prompt: Explain Arrays, C-strings, and structures to a beginner. Provide short code examples for each concept.
Purpose: Tell the AI what specific topic the user wants to learn at this time and make it easier to understand.

Step 3: Create a Practice Plan
Prompt: Create a daily practice plan (30 min per day) for a beginner who wants to improve their C programing skill. Accessible tool: Visual Studio Code. Include variables, loops, functions, arrays, C-strings, and structures. Organize the plan into a table with the day, topic, coding exercise, and learning objective. Arrange the exercises from easiest to most difficult.
Purpose: This prompt includes specific constraints such as programming language, available tools, daily practice time, and learning objectives. And table formats to make the learning plan organized and easy to follow.

Step 4: Evaluate Code and Provide Feedback
Prompt: Review the code I provide. Check for syntax errors, logical errors, and possible improvements. Explain any errors step by step using beginner-friendly language. Do not immediately rewrite my entire program. Guide me with step-by-step instruction to fix any problems appeared in my code.
Purpose: This prompt allows AI to provide personalized feedback while encouraging independent problem-solving. Asking for hints instead of complete solutions helps the learner understand mistakes and improve debugging skills.
